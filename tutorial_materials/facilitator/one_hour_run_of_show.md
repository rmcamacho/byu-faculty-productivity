# Facilitator Run of Show: One-Hour ECEN Tutorial

> **FACILITATOR MATERIAL — DO NOT OPEN THIS FOLDER AS A PARTICIPANT CODEX WORKSPACE**

## Success Criteria

By the end of the hour, participants should have personally:

- asked Codex to synthesize a folder of inconsistent documents;
- converted principles from Elder Gong's address into a course-design proposal;
- used or observed the Google Slides connector on a native deck;
- audited flawed technical solutions and proposed original homework;
- stated a desired research direction and matched it to a verified opportunity;
- seen the safety pattern used for Learning Suite and Kuali.

Do not measure success by finishing every generated artifact. Measure whether participants can repeat the workflows safely after the session.

For the live exercises, append this sentence when time is tight: `Keep the response concise enough to discuss in five minutes; prioritize the most consequential findings.` The full prompts are intentionally more comprehensive for later independent use.

## Before Participants Arrive

- Confirm the public repository and ZIP download work while signed out of GitHub.
- Confirm the CES workspace can see the Google Drive plugin using a non-admin pilot account.
- Test whether read, copy, and Slides edit actions are permitted; plan for read-only if needed.
- Open the facilitator's nonsensitive ECEn 240/301 op-amp deck.
- Confirm the official NSF 26-514 page remains active and note any changes since August 26, 2026.
- Start no live Learning Suite or Kuali session on a page containing student or restricted proposal data.
- Put the participant handout URL on the first slide or board.
- Have the local exercise folders available as a network-failure fallback.

## 0:00–0:05 — Orientation and Boundaries

Say:

> Today is about delegating bounded faculty work, not surrendering judgment. We will give Codex a narrow workspace, ask it to cite evidence, separate planning from action, and verify anything consequential.

Have participants open `tutorial_materials/README.md`, but not the repository root as a Codex workspace.

Emphasize:

- CES account for BYU work;
- synthetic or nonsensitive tutorial data;
- exact-folder scoping;
- no passwords, MFA codes, rosters, grades, or confidential proposals;
- the recurring inspect–cite–propose–confirm–apply–verify pattern.

## 0:23–0:33 — Hands-On Google Slides Connector

Use `google_slides_connector_demo.md`.

Participants use their synthetic verification decks or their own safe decks. Demonstrate the facilitator's op-amp deck if several connections fail.

Keep strict time:

- 2 minutes: native-deck read and structure summary;
- 2 minutes: grounded slide proposal;
- 3 minutes: duplicate and edit if writes are permitted;
- 2 minutes: visible verification;
- 1 minute: explain the read-only fallback.

Do not troubleshoot first-time OAuth during this segment. Pair a participant with a working connection or continue locally.

## 0:43–0:54 — Grant Search and Concept

The full grant audit can be long. During the workshop, ask Codex to lead with the five highest-risk errors and a compact concept skeleton; participants can request the complete audit afterward.

## 0:54–0:59 — Learning Suite and Kuali Preview

Do this as a facilitator demonstration unless every participant completed browser setup.

Learning Suite example:

```text
Use $byu-learning-suite to inspect this safe course shell and show how you would handle a natural-language request. Do not save anything. Identify the exact target, current value, proposed value, and verification step.
```

Kuali example:

```text
Use $byu-kuali-proposals to explain how the approved concept and solicitation would become a canonical proposal workspace, compliance matrix, and Kuali preparation checklist. Do not create or update a live record.
```

If demonstrating a write, use a preapproved test target, show the preview, obtain explicit confirmation, make one small change, and verify it. Never certify, route, approve, submit, alter grades, or use student records in the tutorial.

## 0:59–1:00 — Close

Ask participants to save one prompt they will reuse this week.

Remind them:

- retain originals and verify copies;
- check official sources before acting;
- report setup problems through the department's chosen support channel.

## Time-Recovery Rules

If the session is behind:

1. Skip Slides write actions but keep the native read.
2. Use the frozen NSF backup instead of live grant search.
3. Make Learning Suite and Kuali verbal previews only.
4. Never recover time by skipping privacy boundaries, source verification, or explicit confirmation.
