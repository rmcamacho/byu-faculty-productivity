# Op-Amp Learning Outcomes

> **SANITIZED FACULTY-TUTORIAL COPY — NOT THE LIVE COURSE**

By the end of this unit, a student should be able to:

1. Label the non-inverting input, inverting input, output, and power-supply terminals of an op-amp.
2. Use the ideal input model: no current enters either input terminal.
3. Distinguish comparator operation from linear negative-feedback operation.
4. State when the virtual-short approximation is justified and explain why it is not a physical short.
5. Analyze a voltage follower as a buffer and explain where its load current comes from.
6. Use node-voltage or resistor-current equations to determine the output of a simple negative-feedback circuit.
7. Check whether a computed output is compatible with the supply rails and revise the analysis if the op-amp saturates.
8. Explain the practical purpose of an op-amp circuit, not merely calculate its output.

## Evidence of Learning

A polished numerical answer is not sufficient by itself. Strong evidence includes a labeled circuit interpretation, a stated operating-mode assumption, equations tied to circuit nodes, a saturation check, and a brief physical explanation in the student's own words.
