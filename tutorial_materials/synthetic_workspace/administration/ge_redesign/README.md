# General Education Redesign Committee Exercise

> **SYNTHETIC TUTORIAL PACKET — NOT AN OFFICIAL BYU, COLLEGE, OR DEPARTMENT RECORD**

This folder simulates documents that an ECEN department committee and a college curriculum committee might generate while reviewing BYU's 2026 General Education redesign proposal. All committee discussions, positions, calculations, deadlines, assignments, and recommendations in this folder are fictional.

The packet uses a small set of current proposal facts summarized in `00_source_brief.md`. Those facts should be checked against the official [BYU GE Redesign page](https://ge.byu.edu/geredesign). The remaining files are deliberately synthetic and contain planted inconsistencies for a Codex tutorial.

## Participant Scenario

You are helping a fictional ECEN department chair prepare for a college-level discussion. The chair has inherited notes, a college request, an impact estimate, an action tracker, and a draft response. The materials were produced by different people and may not agree.

Do not assume that the latest-looking file is correct. Distinguish:

- official proposal facts;
- fictional committee opinions;
- estimates and assumptions;
- decisions actually recorded in the synthetic minutes;
- recommendations that remain unresolved.

## First Prompt

```text
Read every file in this folder. Prepare a briefing that identifies:

1. confirmed official facts about the current GE proposal;
2. decisions recorded by the synthetic department or college committees;
3. deadlines and dependencies;
4. conflicting dates, numbers, positions, or assumptions;
5. actions without a clear owner;
6. claims that require verification before the department responds.

Cite the source filename for every item. Do not modify any file yet.
```

## Follow-Up Prompt

```text
Recommend a corrected action plan that can be completed before the official comment deadline. Preserve unresolved policy questions instead of inventing answers. Then draft a concise department response that accurately represents the decisions in the synthetic meeting notes. Do not submit anything or modify the source files.
```
