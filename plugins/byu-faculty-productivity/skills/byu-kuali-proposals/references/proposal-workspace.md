# Proposal Workspace

Use a proposal-specific folder so another person or Codex session can resume without relying on chat history.

Recommended contents:

- the current solicitation, amendments, FAQ, and reviewer instructions;
- a compliance matrix tied to official requirements;
- one canonical source for each narrative component;
- the original budget template plus a separate working copy;
- generated upload files;
- a concise proposal state file.

The state file should record:

- sponsor, opportunity, deadline, proposal title, and responsible people;
- Kuali proposal number and budget name when available;
- canonical source files and generated uploads;
- last verified sponsor-document versions;
- last live Kuali sync time and what was confirmed;
- open questions, approvals needed, and remaining tasks.

Do not overwrite the original budget template. Label planning workbooks clearly if they are uploaded as internal support rather than as the official budget.
