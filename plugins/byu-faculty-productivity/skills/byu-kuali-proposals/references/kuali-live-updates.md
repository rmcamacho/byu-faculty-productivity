# Live Kuali Updates

Use an authenticated browser session supplied by the user. Never request or store passwords, MFA codes, cookies, or browser-profile data.

## Safe Pattern

1. Confirm the visible proposal number, title, principal investigator, sponsor, and opportunity before acting.
2. Inspect the relevant page or embedded frame and summarize its current state.
3. Preview the exact fields or attachments to change, including old and new values.
4. Obtain explicit confirmation immediately before the live write.
5. Make one small coherent change set.
6. Save inside a dialog when the dialog has its own Save control, then save the page when it has a separate Save control.
7. Re-open or re-read the record and verify persistence.

Prefer replacing an attachment through its Details dialog over delete-and-re-add when preserving its record is important. If the page shows an incident or incomplete load, try the page's normal Retry once; then stop and report the state instead of forcing navigation or repeating writes.

Certification, routing, approval, and submission are distinct consequential actions. Never infer permission for one from permission to edit fields or upload files.
