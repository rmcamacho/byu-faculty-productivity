# Course Copy And Setup

Use this procedure for a new term shell or a course copied from a prior offering.

## Discovery

Record the visible destination course title, term, section or combined sections, and URL. Separately record the intended source term and course. Present both identities together so the instructor can catch a source/destination reversal.

Inspect the current destination before copying. Note whether it already contains assignments, syllabus content, schedule entries, or student-visible material.

## Preview

Before a live action, summarize:

- source and destination courses;
- content expected to be copied or replaced;
- setup fields to change, such as title, grading mode, course combinations, site mode, or messaging settings;
- fields intentionally left unchanged;
- any evidence that the destination is not empty.

Course copy and final Save actions require explicit confirmation. Afterward, inspect the destination again and compare its visible state with the preview.
