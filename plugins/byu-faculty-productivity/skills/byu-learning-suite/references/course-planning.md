# Course Planning And Updates

## Build A Reviewable Plan

For schedules and assignments, create a table or CSV with stable item names or IDs, current values, proposed values, and a reason. Keep date and time separate when only one is changing.

Check the plan against:

- the official term start and end dates;
- the course meeting pattern;
- holidays, reading days, and university exam dates;
- workload bunching and prerequisite ordering;
- linked content that should remain attached to schedule items.

For a prior-term comparison, distinguish direct copies from date shifts and substantive content changes. Never assume that the same weekday offset works across holidays or final-exam periods.

## Apply And Verify

Use dry-run or preview behavior when available. Apply only rows included in the approved plan. Preserve existing times when the plan changes only dates, and preserve existing HTML or links when the plan changes only labels or placement.

After saving, re-inspect every affected item or a complete affected table. Report mismatches instead of repeatedly retrying an uncertain action.
