# Student Data

Rosters, grades, accommodations, and individual exceptions can contain PII and private educational records. Opening a file or browser page for AI-assisted work counts as data access.

- Default to not opening, exporting, or processing identifiable student data.
- Use the BYU CES ChatGPT Edu identity for BYU work; never use a personal ChatGPT account for student information.
- If a task requires names, photos, contact information, usernames, NetIDs, student IDs, or other identifiable information, require explicit institutional AI Executive Committee approval before access. Instructor permission alone is not sufficient.
- When approval is absent, help the user construct a de-identified workflow or complete the sensitive step outside the AI workflow.
- When an approved export is necessary, minimize fields to the stated purpose and choose a destination controlled by the instructor.
- Do not place student data in a plugin, tutorial example, repository, or shared prompt.
- Use synthetic names and identifiers for demonstrations.
- For an institutionally approved individual exception, preview only the minimum necessary record and require confirmation immediately before saving.
- Never infer or recommend an accommodation decision. Apply only the instructor's or authorized office's stated decision.
