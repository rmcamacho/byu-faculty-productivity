# Student Data

Rosters, grades, accommodations, and individual exceptions are private educational records.

- Export only when the instructor explicitly requests it and choose a destination they control.
- Minimize fields to the stated purpose.
- Do not place student data in a plugin, tutorial example, repository, or shared prompt.
- Use synthetic names and identifiers for demonstrations.
- For an individual assignment exception, preview the student, assignment, old value, and new value together; require confirmation immediately before saving.
- Never infer or recommend an accommodation decision. Apply only the instructor's or authorized office's stated decision.
